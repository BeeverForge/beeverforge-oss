**`box prove` is now a catalogue action, `box_prove`, reachable through both transports with the catalogue's authorization and audit.** Through the API it starts the proof on the worker and answers the running proof's handle, and an unknown project answers a reason rather than an error. The CLI verb maps over the action with the same exit codes; a branch whose manifest cannot be read no longer prints the clone's credential, and a box that fails to start is said in one sentence.
