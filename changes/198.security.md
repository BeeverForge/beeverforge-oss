**More of the credential shapes another machine holds are withheld wherever the agent's or the reviewer's words are quoted.** The pull request body, a briefing, a facts file and a refused source's note now show `[credential withheld]` for an `Authorization` value written with no scheme (16 or more token characters with a digit), the value of an `X-Api-Key` or `Api-Key` header, the value assigned to a secret-named name (`export OPENAI_API_KEY=…`, `password=…`, `passwd: …`, a JSON `"api_key"`), a presigned URL's `X-Amz-Signature`, and the secret parameter of a `Digest` or SigV4 header whose parameters run past 1,000 characters. Only the value is withheld: the header or variable name stays. Prose that only names these headers or keys ("password= is required", "X-Api-Key: required on every call") is quoted as written, and so is a value with no digit, padding or lower-then-upper letter pair in it. A value of that shape under a secret-named name is withheld even when it is no secret, for example an 8-digit count under `max_tokens:`.
