**A project's box image can now be set through the catalogue.** `project_set_box_image` (`project`, `image`) writes the project's `box.image`, and an empty `image` clears it back to the deployment's default; it answers the project and its new value, and setting the same image again changes nothing.
It refuses, as `INVALID` with "Nothing was changed", a reference that does not parse and an image the deployment's sandbox kind cannot honour — the same check `box prove` makes before it starts. It is guarded like the other `project_set_*` rows and leaves one audit record, allowed or refused.
`beeverforge project set-box-image <name> <image>` sits beside `set-model`, and the panel shows the current image with the other project settings.
Changing the image marks the project's recorded box proofs stale, so pickup is held with that reason and the next job or `box prove` proves the box in the new image.
