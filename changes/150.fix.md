**A registry that spells one GitHub organisation two ways, such as `Acme/api` and `acme/web`, is one organisation again.** GitHub logins ignore case, but the registry grouped its projects by spelling, so `beeverforge project add` refused the second project, `ProjectRegistry.list` logged a false `BEEVERFORGE_REGISTRY_SPANS_INSTALLATIONS` warning, and `beeverforge doctor`'s `installation_scope` line failed a correct deployment. The registry now groups owners without case and names the organisation by the first spelling it holds; a factory board or requirements repository in the same organisation, spelled differently, is no longer warned as foreign.
