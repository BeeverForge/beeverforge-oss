**A board whose pickup column is not named the way BeeverForge expects (`TO-DO`, or `To Do` on Azure Boards) is mapped by hand in this release.** No command or panel setting reads or sets a project's board columns yet: add the mapping to the project's tracker options in the registry (on the compose stack, `/var/lib/beeverforge/registry.yaml` on the worker's state volume) as a quoted JSON string, `columns: '{"todo": "<your column>"}'` (`status_map` on a Jira project), or set `pickup_status` to that column's name. `beeverforge doctor` says when a board has no such column, and gives the line to add. 0.3.0 reads and sets the mapping through the catalogue, the command line and the panel.
