**A board whose pickup column is not named `TO-DO` is mapped by hand in this release.** No command or panel setting reads or sets a project's board columns yet: add the mapping to the project's tracker options in the registry (on the compose stack, `/var/lib/beeverforge/registry.yaml` on the worker's state volume) as a quoted JSON string, `columns: '{"todo": "<your column>"}'`, or set `pickup_status` to that column's name. `beeverforge doctor` names the missing column and the line to add. 0.3.0 reads and sets the mapping through the catalogue, the command line and the panel.
