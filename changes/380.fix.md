**A GitHub repository typed in another case, such as `acme/api` in the registry and `Acme/api` on the Projects board, is one repository again.** GitHub ignores case in repository names and its Projects board answers in GitHub's own spelling, but the board compared the two by spelling: a card of the project's own repository came out as `Acme/api#12` instead of `12`, a second identity for the same ticket, and moving or ranking that card failed with "no card for the issue". The board now compares repositories without case and keeps the spelling it was given for anything it shows.
