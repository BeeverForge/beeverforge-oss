**An Azure DevOps repository typed in another case, such as `Docs/API` for an adapter of `api` in project `Desk`, is the adapter's own repository again.** Azure DevOps ignores case in repository and project names, but the forge compared the ref's repository with its own by spelling, so it read `Docs` as another project and cloned from there. The forge now compares the names without case, so that clone comes from `Desk`, and the URL keeps the spelling given. A ref naming another repository, such as `Docs/web`, still clones from the project it names. The Azure Boards tracker matched its `areas` map by spelling in the same way, so a card of `acme/API` was not filed under the area mapped to `acme/api`. It now matches without case too.
