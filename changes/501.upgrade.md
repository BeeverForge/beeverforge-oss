**OpenFactory 0.7's `openfactory` command and `openfactory` import name work again, until 1.1.** The `openfactory` command runs `beeverforge`, with the same output on stdout and the same exit codes, and prints one warning on stderr naming `beeverforge`. An add-on that does `import openfactory` or `from openfactory.<module> import …` gets the `beeverforge` package and the same modules, with a `FutureWarning` naming the new import. BeeverForge 1.1 removes both names: change scripts to call `beeverforge`, and add-ons to import `beeverforge`.
