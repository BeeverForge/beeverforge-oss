A held job whose workflow has ended can be closed with the action `dismiss` (project, issue, optional why): it writes one `dismissed` state event carrying who closed it and why, and leaves the card where it is, so the job leaves the attention list without a closed ticket going back to the backlog the way `skip` would send it. It is refused with CONFLICT, naming `skip`, while the workflow still runs, and with NOT_FOUND when no job ran for that issue; repeating it writes nothing more, and every call, allowed or refused, leaves its audit line. Run it as `beeverforge job dismiss <project> <issue> [--why ...]`, or from the Dismiss button on a held job's row in the panel's attention list.
