**A hook or `core.hooksPath` planted in the shared repo cache no longer runs on the host.** The worktree box adds its trees from the shared repo cache, whose hooks directory and config a pass can write and which survive a job's cleanup. Its push ran without `--no-verify`, so a planted `pre-push` hook ran on the host and was handed the authenticated remote URL. Every git command the worktree box, the repo cache and the worker's knowledge refresh run on the host now passes `-c core.hooksPath=/dev/null`, and the box's push also passes `--no-verify`. This stops hooks only: programs and URL rewrites a pass sets through the cache's own git config or attributes are not covered yet (tracked in #386), and the container box's per-job clone is tracked in #382.
