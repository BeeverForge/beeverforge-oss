A tracker write (state, comment, label, assignee) that fails on a forge's rate limit is now queued and applied after the limit resets, newest state per ticket winning and each entry at most once. The queue is one file in the project's log directory, shared by the project's runners under a file lock, so it survives a restart. It is drained when a job starts and when it ends, and on the next write; an entry whose reset had not passed when its job ended waits in the file for the project's next job, and with no further job it stays there.
