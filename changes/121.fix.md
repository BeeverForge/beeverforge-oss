**A Jira `scope_jql` with a `)` it never opened is refused when the tracker is built.** Such a scope closed the parentheses the scope is wrapped in, so a condition like `labels = "bf-api") OR (labels is not empty` read every labelled issue on the whole Jira site as the project's queue; the refusal names the scope and the character of the stray `)`, and parentheses inside quoted strings are still accepted.
