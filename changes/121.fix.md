**A Jira `scope_jql` with a `)` it never opened, or a string it never closes, is refused when the tracker is built.** Such a scope closed the parentheses the scope is wrapped in, so a condition like `labels = "bf-api") OR (labels is not empty` read every labelled issue on the whole Jira site as the project's queue; a backslash before a quote, inside or outside a string, no longer hides the stray `)`. The refusal names the scope, the character at fault and what to change in `tracker.options.scope_jql`, and parentheses inside quoted strings are still accepted.
