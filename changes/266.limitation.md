**An OpenFactory 0.7 deployment does not upgrade to BeeverForge 0.1.0 in place.** BeeverForge 0.1.0 reads none of OpenFactory's names yet: no `OPENFACTORY_*` variable, no `~/.openfactory` or `.openfactory/` directory and no `openfactory.adapters` entry point, and there is no `openfactory` command. Install BeeverForge fresh, beside the 0.7 deployment or in its place; OpenFactory 0.7 receives security fixes until BeeverForge 1.0. The upgrade in place, which reads the old names, is planned for 0.2.0.
