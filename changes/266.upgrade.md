**An OpenFactory 0.7 machine's operator files are read where 0.7 left them.** On a machine whose home has `~/.openfactory/` and no `~/.beeverforge/`, the registry, the approver store, the resume handles, the gate key, the board database, the box proofs and the one-machine deployment's `env` file are read and written there, and a project registered by its checkout keeps its journals in `.openfactory-logs/` beside it while `.beeverforge-logs/` does not exist. Once `~/.beeverforge/` exists, it is the one read and `~/.openfactory/` is not: rename the directory rather than creating the new one beside it.
