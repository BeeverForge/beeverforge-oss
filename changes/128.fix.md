**A long comment or close reason on a GitHub card is posted.** A text GitHub accepts failed once it passed about 43,690 characters in a 3-byte script such as Chinese or Japanese, because the operating system refused it as one command-line argument. Comments and close reasons now go to `gh` on standard input. A close reason is posted as a comment just before the close, and if the close is then refused, the error says the reason was posted and the issue is still open. A text over GitHub's 65,536 characters is refused by name before it is sent, and a byte that is not UTF-8 is sent as the replacement character.
