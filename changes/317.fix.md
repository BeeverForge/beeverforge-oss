**Measuring a ref of a local project refuses a symbolic link or a file at its checkout path, and no longer prunes other worktrees.** `box prove --ref` reused a fixed path under the repository cache and never looked at what stood there, so a symbolic link there had git remove, or check out into, the tree it named; such a link or file is now refused in one sentence naming it, before git is asked anything, and only this path's own stale registration is cleared instead of running `git worktree prune`, which dropped every worktree whose directory was momentarily missing.
