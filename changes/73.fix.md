**`python -m beeverforge.runtime.temporal.schedule` and `python -m beeverforge.runtime.temporal.starter` say so when there is no engine to reach.** Both ended in a traceback; they now wait for the engine as the worker does, then name the address they tried and how to start an engine or point to one, and exit 1.
