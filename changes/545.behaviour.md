**A gate on a small machine can now leave out the tests that read the whole source tree with `-m "not whole_tree"`.** About 290 tests walk or parse the repository (`rglob`, `os.walk`, `git ls-files`) and now carry the `whole_tree` marker, which a guard keeps true in both directions; CI's jobs still run every one of them, with the same selection as before, so nothing is skipped before a human merges.
