**`beeverforge doctor` reads a Jira board with the token the project's `tracker.options.token_env` names.** Its board, intake, stages and API-budget checks built the Jira tracker without the project's own credential, so where `JIRA_API_TOKEN` was not also set, `board_columns` reported the board as unreadable and told you to set a variable that was already set and valid. The doctor now resolves the token the way the poller does.
