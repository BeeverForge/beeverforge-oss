A held job whose ticket was closed by a merged pull request now ends as merged: one merged event naming the pull request and one ending row, so throughput counts it; a ticket closed without a merge, or with no pull request, ends as closed and is not counted, and a pull request that cannot be read writes nothing. Loading the attention list (GET /api/attention) is what records these endings, under a lock per job and one shared time limit; a job the limit cuts off stays listed with a note.
