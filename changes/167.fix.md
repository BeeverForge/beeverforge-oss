**`beeverforge env context --ask` no longer asks in your own checkout.** The tech-lead harness was asked in the checkout the command was pointed at, which on a local deployment is the repository you commit from. On Kimi Code, which is read-only by instruction only, a question that disobeyed left its file in your working tree for you to commit. Each question is now asked in a temporary copy of the checkout, holding the files git tracks and the untracked ones it does not ignore, as they are in your working tree, and the copy is removed once the question is answered. The copy is made on every `--ask`; a repository with many untracked, unignored files costs that copy.
