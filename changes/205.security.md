**A message refused at the gate is no longer written to the log.** The three denial warnings (out of scope, an installation row, not an admin) printed every parameter, so a `product_say` message was logged in full. A log line now prints a parameter as given only when it is on an explicit list of ids, numbers, enums, booleans and project, issue and repository names; every other value is printed as its length and a SHA-256 digest, so a new parameter that takes a person's words is never logged whole by omission. A secret is still masked.
