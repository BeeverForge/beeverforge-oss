**Approving a staged proposal whose write did not happen no longer answers success.** When the product role refused the write, `product_answer` now answers that refusal's code (403, 404, 409 or 400) with `data.refusal`, and when the write broke it answers 500 `failed` with a `data.reference`; `beeverforge product ask … --propose --yes` exits non-zero for both, and the panel no longer draws them as an ordinary answer.
