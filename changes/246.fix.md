**A rebuilt worker brings its new harness versions to the boxes.** The harness toolbox was copied to its volume once and then kept for good: its stamp recorded the harnesses' names but not their versions, so a worker image rebuilt with a newer `claude` (or `codex`, `kimi`, `opencode`) left every box on the old copy. Current models refuse an old `claude`, and the only way through was installing the new one into the volume by hand. The stamp now records each package's version, the worker copies the toolbox again on the next boot when the baked versions differ, and `beeverforge box prove` prints the versions the boxes run. A toolbox stamped before this release records no versions, so it is copied once on the first boot after the upgrade.
