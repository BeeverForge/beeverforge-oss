**A box proof or a doctor check run with no root keeps its working trees where a job looks.** The worktree box put them under `.beeverforge-worktrees` in the directory the command was started in, which could be inside a person's checkout and which a later command started elsewhere did not find. They now go to `.beeverforge-worktrees` beside the repository cache (`BEEVERFORGE_REPO_CACHE`), the same root a job's box uses.
