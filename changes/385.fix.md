**A GitHub repository typed in another case is one repository at four more places.** After #380 fixed the Projects board, four other places still compared repository names letter for letter, case included. Now each compares them without case and keeps the registry's spelling for anything it shows or writes. A card typed `Acme/api#42` on the product page of a project registered as `acme/api` is now that project's own card, where before it was refused as a card of another repository. Such a card is now checked out under the project's own key, also for an Azure DevOps name qualified in another case, where before it got a second checkout under a foreign key. Running `project add` again with the repository typed in another case now answers that nothing was changed, where before it refused with a conflict. A `product.yaml` source naming the project's own repository in another case is now labelled as the project's own mount and listed first.
