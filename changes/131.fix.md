**A review that hits the usage limit, or is not logged in, pauses or holds the job instead of rejecting the change**, and a review run that ended in error — or was killed or timed out before it finished — is never read as a verdict. A review that did not complete holds the job: no pull request is opened and nothing is merged, and the hold says the review did not complete and why. Wherever such a review is reported it says the review did not complete, with no score: the job's journal, the pull request's description, and the pull request review, which is posted as a comment rather than a request for changes. The first round reports that the reviewer produced nothing readable, not a rejection.
