**`box prove` checks what it is asked.** When a project's registry key differs from its own name, the command now proves in place under the name it was given instead of starting a proof on the worker and rendering its "running" answer as a verdict; the command also refuses any running answer in words, and a `--repo` that is not `owner/name` is refused on the worker path before anything starts. A second ask with a different image or box now gets its own proof on the worker rather than joining the one that runs.
