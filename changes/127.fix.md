**A long pull-request text in any script reaches GitHub.** Opening a pull request, bringing an open one up to date, reviewing one and rewriting its description passed the whole text to `gh` as one command-line argument, which Linux refuses over 131,072 bytes: a text GitHub accepts (up to 65,536 characters) failed from about 43,690 characters in a 3-byte script such as Chinese or Japanese, as a raw `OSError` or a description left on an earlier attempt. The text now goes to `gh` on its standard input, and an argument the kernel still refuses is a named failed call that says to send the text on stdin.
