**The environment rehearsal says what git refused.** A commit git refuses (exit 128, such as dubious ownership or a lock) now fails the diff step with git's exit code and words and asks you to make git usable on the workspace in the box, instead of telling you to check for a missing git or base branch; a `git status` git refuses after an empty diff no longer reads as an agent that wrote nothing. A commit with nothing to commit on a clean tree still goes on quietly.
