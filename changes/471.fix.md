**A yes on one product's page no longer performs a proposal staged on another product.** A person's own conversation has the same key on every product page, and the proposals a worker holds in memory were kept by that key alone, so a yes on one product's page could confirm the proposal another product's role had staged last and record it in the wrong context repository. Each staged proposal now carries its product, and only that product reads it, confirms it or sets it aside.
