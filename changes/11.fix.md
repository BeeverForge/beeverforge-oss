**A job parked on failing gates now says which gate failed and pushes the work it leaves behind.** The park said only "validations failed after N repair attempt(s)"; it now names each failing blocking gate (up to three, then how many more), its command and the last lines it printed, with any credential in them withheld — including a credential the gate's environment held under a name that does not look like one, such as `AZURE_DEVOPS_PAT` or a project's `token_env` — and with `#12` written `card 12`, and the journal keeps each gate's whole tail. The agent's commits are pushed to the job's branch, which the park names so a Resume continues them. When the agent wrote nothing, its changes could not be committed, or the push fails, the park says nothing was pushed, why, and where the work is: on the worktree box, the local branch and its repository, to push by hand before resuming; on the container box, that it was discarded. **A push no longer replaces commits it did not start from.** Every push of a job's branch is `--force-with-lease` over the tip the job started from (or over nothing, for a fresh start), so a person's fix on a parked branch, or the work a park preserved there, is never overwritten by a later run of the card: the job is held instead, naming the branch, and Resume continues from it.
