**Code and links the reviewer quotes reach the pull request as written.** Since the reviewer's summary and findings stopped linking issues and notifying people, `#12` became `card 12` and a name carried an invisible space even inside a closed code span, a fenced block or an address GitHub turns into a link, so `` `a#1` `` read `` `a card 1` `` and an address holding `/@someone` or `#123` pointed somewhere else. Nothing links or mentions there, so those are now left as written, bare or in angle brackets. Outside them the words still link nothing, and so does a backtick that never closes, a table (whose `|` can end a code span in its cell), and a closing keyword inside code, which a squash commit message reads with no code around it: `Closes #12` and `Closes GH-12` read `Closes card 12`, and `Closes` before a link to an issue or a pull request reads `Closes owner/repo card 12`.
